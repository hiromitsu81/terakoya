# 外部連携サービスのロゴの置き場所と入手先

各社のブランドガイドラインにしたがって入手したロゴを、下のファイル名で置くと、integrations.html に自動で表示されます（.svg か .png。横長・透明背景がおすすめ）。ロゴがないあいだは頭文字で表示されます。

入手のしかたは4つです。

- **公開ページからダウンロード**：そのページのガイドライン（余白・最小サイズ・色を変えない）を読んでから使う。
- **広報に依頼**：公開の配布ページが見つからないもの。下の依頼文で、各社の広報・提携窓口に頼む。
- **契約者の管理画面から**：決済・出店サービス。契約したあとに管理画面の素材を使う。
- **許諾が必要**：Microsoft・楽天・Salesforce・Booking.com など。許諾が出るまでは、ロゴを置かず名前の文字だけで表示する。

URLは2026年11月19日時点。公開ページの場所は変わることがあるので、見つからないときはサービス名に「ロゴ ガイドライン」「brand assets」「press kit」を付けて探す。

## 広報への依頼文（そのまま使えます）

```
件名：貴社サービスロゴ掲載のご相談（連携サービス一覧ページ）

〇〇株式会社 広報ご担当者さま

HATHA LAB（ハタラボ）の澁谷と申します。
AIエージェントサービス「ハタボ」のサイトで、連携できる外部サービスの一覧ページを公開しています。
https://www.hatha-lab.com/integrations.html

こちらに貴社の「〇〇」を、連携先として掲載させていただきたく、
ロゴデータ（SVGかPNG）と、ロゴ使用のガイドラインをいただけないでしょうか。
掲載のしかたや表記にご指定があれば、それに合わせます。

HATHA LAB　澁谷 浩充
info@hatha-lab.com
```
