# バターちゃんとチーちゃん

家族OS（学問ススムくんの家族LINEグループ）とつながる、声で話す家族のAIペット。
バターちゃん（お皿の上のバター）と、柴犬の子犬チーちゃんが一緒の画面にいる。

- ページ：この `index.html`（GitHub Pages）
- 頭脳：AI寺小屋のGASプロジェクトの `butter.gs`（`family.gs` の記録・ポイントを読む）
- 会話：Claude（速いモデル）。キーはGASのスクリプトプロパティにだけ置く

> GASのURL・合言葉・スプレッドシートIDは、このリポジトリ（公開）には書かない。

---

## しくみ

```
家族LINE（報告・宿題・日記） ─┐
                              ├─ GAS（family.gs / butter.gs）＋ スプレッドシート「記録」
バターちゃんのページ（声） ────┘        │
                                       ├─ Claude（会話）
                                       └─ SwitchBot（家電、任意）
```

ページは15秒ごとに `poll`、話しかけると `chat`、ガチャは `gacha` をGASに送る。
すべて `{app:'butter', pass:合言葉, action, …}` を `text/plain` でPOST。

| action | 返すもの |
|---|---|
| `poll` | LINEの「バターちゃん 〇〇」の読み上げ待ち ＋ 様子（state） |
| `chat` | 返事 `text`、気持ち `emotion`、様子（state） |
| `gacha` | 出たアイテム（または券なし）＋ 様子（state） |

## 育てるルール

### 溶ける（たまごっち）
最後に話しかけられた時刻、またはLINEの報告の時刻からの経過で4段階。

| 経過 | 姿 |
|---|---|
| 〜6時間 | ひんやり |
| 6時間〜 | やわらか |
| 14時間〜 | とろとろ（しずく） |
| 24時間〜 | とけちゃった（水たまり） |

### チーちゃんの成長
承認済みポイント（記録シートの獲得pt）の合計で育ち、芸を覚える。

| pt | 芸 |
|---|---|
| 10 | おすわり |
| 30 | おて |
| 60 | ふせ |
| 100 | まわれ |
| 160 | ジャンプ |

「チーちゃん、おて」はページ内で処理（AIを呼ばない）。まだの芸は「あと〇pt」と教える。

### 進化（報連相の連続日数）
報告・宿題・日記・進捗・写真・動画のどれかがある日が何日続いたか。今日まだでも昨日まで続いていれば切れない。1日あくと元にもどる。

| 日数 | 姿 |
|---|---|
| 3日 | おうかんバターちゃん |
| 7日 | はちみつバターちゃん |
| 30日 | きんのバターちゃん |

### 一人ずつのおさいふ・もちもの
- 報連相のポイントは一人ずつのおさいふにたまる（記録の呼び名ごと、倍率込み）。チーちゃんの成長と進化は家族みんなのまま
- ガチャ10pt・UFOキャッチャー5pt（一人1日1回おためし無料）。始めるとき「だれの？」で名前を選ぶ（声で「エイトのガチャ」も可、ミニアプリはLINEの本人）
- 出たアイテムはその子のもちものボックスへ。バターちゃんたちには「貸してあげる」形で、持ち主の名前が出る
- GASのデータ：BUTTER_GACHA = { equip, owner, people: { 名前: { spent, owned, prizes, ufoFree } } }

### ガチャ
- 報連相の承認済みポイント 10pt でガチャ券1枚（ポイントは減らない）
- 「バターちゃん、ガチャ回して」で回す（LINEの「ガチャ」はススムくん本体と重なるので使わない）
- 出現率：ノーマル70／レア25／スーパーレア5。出たものは自動で装備
- 13種：むぎわらぼうし・コックさんのぼうし・サンタぼうし・まるめがね・サングラス・ちょうネクタイ・ピンクのリボン・きんのバターざら、チーちゃんのあおいバンダナ・きんのくびわ・あかいボール・ほね・フリスビー
- 持ち物はスクリプトプロパティ `BUTTER_GACHA` に保存

### 表情
返事の先頭の気持ちタグで切りかえ：えがお・わらう・びっくり・しょんぼり・てれる・かんがえ・わくわく（＋ねむり・とろけ）。

## ふたりの役割と記憶
- **バターちゃん**＝おうち担当。話すのは家のPCのClaudeアプリ（プロジェクト「バターちゃん」）。このページは**見た目担当**（⚙「だれがお話しする？」で切りかえ）
  - 見た目モード：マイクの音量で口が動く、聞こえた言葉で表情が変わる、「チーちゃん、おて」「バターちゃん、ガチャ回して」に反応、話し声がしたらGASに `touch`（溶けない）
  - 会話モード：これまで通りページがGASのClaudeに聞いて、ブラウザの声で話す（サービス版の土台）
- **チーちゃん**＝お出かけ担当。スマホのClaudeアプリ（プロジェクト「チーちゃん」）。外ではしゃべれる
- 記憶はGoogleドライブのフォルダ「バターちゃんとチーちゃん」でつなぐ（IDはGASとプロジェクト設定にだけ書く）
  - `バターちゃんの様子.txt`：GASが20分ごとに書く（溶けぐあい・進化・芸・ガチャ券・今日の予定と報告。家計は入れない）
  - `おうち日記 …` はアプリのバターちゃん、`おさんぽ日記 …` はチーちゃんが、会話のおわりに新しいファイルで書く
  - `バターちゃんのおうち日記.txt`：会話モードでの会話の要約（GAS）
  - どちらのキャラクターも、話す前に様子と最近の日記を読む

## LINEミニアプリ版（スマホ1台）
- エンドポイントURL：このページに `?liff=1&g=<GASのデプロイID>&liffId=<LIFF ID>` をつけたもの
- 本人確認：LIFFのIDトークンをGASが `https://api.line.me/oauth2/v2.1/verify` で確かめ、メンバー表にいる人だけ使える（合言葉なし）
  - LINEログインのチャネルは、ボットと**同じプロバイダー**に作る（ユーザーIDがそろう）
- 話す：「おして話す」→ 16kHzの音をGASへ → Google Speech-to-Text → Claude → Google Text-to-Speech → ページで再生（自分で鳴らす声なので口がずれない）
- GASの設定：`butterGoogleKeySetup`（GOOGLE_SPEECH_KEY）、`butterLiffSetup`（LIFF_CHANNEL_ID）、声は `TTS_VOICE`（`butterVoiceList` で一覧）

## 台本モード（ステージ・スマホ1台）
- URLに `?stage=1` をつける（はじめの画面の「ステージ（台本）モードにする」でも入れる）
- マイクもGASも使わない。大きなボタンをおすたびに、バターちゃんが台本のセリフを話して口が動く。話している間におすと止まる
- 台本は「台本をなおす」で変えられる（この端末に保存）。1行1セリフ、「ヒロ：」の行は話さずに「ヒロさんの番」と出る。行頭の【わくわく】【わらう】【てれる】などで表情
- 100人カイギ（2026-11-16）のかけあい自己紹介用に作った

## 守っていること
- 合言葉が合わない呼び出しには答えない。1日の回数上限（`MAX_PER_DAY`）
- 家計のシートとLINEのIDはClaudeに渡さない
- 大事な話（けが・体調・お金・知らない人）は「パパかママに話してね」
- お風呂は必ず「栓がしまっているか大人に見てもらってね」と言う

## はじめ方（パパ）
1. GASに `butter.gs` を置く（中身を全部置きかえ）
2. `コード.gs` の `doPost` 最上部に1行（入れ済み）：
   `if (typeof butterHandle_ === 'function') { const b = butterHandle_(e); if (b) return b; }`
3. 合言葉：`butterSetPass` を実行（実行後は元に戻す）
4. デプロイを管理 → 新しいバージョン
5. ページの⚙にGASのURLと合言葉。Edgeなら声は「Nanami（Natural）」

### SwitchBot（任意）
1. SwitchBotアプリでトークンとシークレットを出す
2. `switchbotSetup` に書いて実行 → 元に戻して保存
3. `switchbotListDevices` でIDをログに出す
4. `switchbotSetDevices` に「電気」「エアコン」「お風呂（on:'press'）」を書いて実行
